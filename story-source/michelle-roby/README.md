The app is statically exported with Next.js. Assets are stored in `fordivine-upload-to-github/crowned-stories/michelle-roby/` to keep this route self-contained. For rebuilding, copy the `images`, `fonts`, and `fordivine-*.png` files from that route into this source directory's `public` directory, install dependencies, run the build script, and copy the exported `out` contents back to the route. Preserve the configured basePath.
