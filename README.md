# fordivine-experiences
## Shared navigation

The shared glass navigation is adapted from the approved homepage reference. Its HTML, scoped styles, font, monogram, and animation bundle live in `fordivine-upload-to-github/shared/glass-navigation.*` and `nav-*`. The animation bundle includes GSAP with its license notice.

After exporting or rebuilding a static story, run `python3 scripts/apply-glass-navigation.py` before deploying. This updates eligible exported pages and the strict script policy for Amy's story. Kickstart is deliberately excluded. The standalone assessment repository carries the same shared assets and uses canonical FORDIVINE page links.
